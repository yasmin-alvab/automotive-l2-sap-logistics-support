# automotive-l2-sap-logistics-support
Task execution, root cause analysis, and incident resolution log for Tier-2 automotive logistics support


### SAP MM/WM Tier-2 Production Support

- Provided Tier-2 support for SAP ECC Materials Management (MM) and Warehouse Management (WM) modules across a 3-shift production rotation.
- Performed Root Cause Analysis (RCA) on critical support tickets and executed backlog activities, reducing average issue resolution time by approximately 20%.
- Monitored Just-In-Time (JIT) material deliveries via scheduled background jobs and executed corrective actions to prevent production line downtime.
- Processed JIT payment data and analyzed inbound/outbound logistics data streams.
- Prioritized and processed critical Goods Issue (GI) and Goods Receipt (GR) data during high-volume background Job runs while monitoring system resource loads to ensure smooth execution and eliminate production bottlenecks.
- Analyzed and monitored IDocs to identify and resolve data inconsistencies received from the EBON interface.
- Collaborated with end users to execute test scenarios, identify process gaps, implement fixes, and validate changes in the QA environment before transport to Production.
- Executed custom SAP Queries to identify and resolve data inconsistencies in MM and WM database tables as: LTAK, LTAP,LAGP, LQUA, LEIN, LIKP.
- Maintained and configured Work Areas and organizational elements within SAP.
- Executed factory calendar updates and time stream configurations in the production system.
- Implemented process enhancements for factory calendar updates to minimize production downtime risks.
- Developed comprehensive technical documentation based on functional requirements to streamline escalation to the Tier-3 support team (Germany / International).
- Analyzed, documented, and tracked incidents raised to SAP Support, coordinating implementation of SAP Notes with the Tier-3 engineering team.
